一、作品概述
CogniMotion是面向长时程机器人任务的认知—运动协同智能体系统。作品以Agnes Harness为交互与工具调用底座，通过“大脑负责认知规划、小脑负责运动执行”的层级架构，将自然语言目标转化为可执行、可观测、可验证的机器人操作流程。
作品关注的核心问题是：单步动作能力如何转化为持续、可靠的长程任务能力。长任务不仅要求机器人完成抓取、放置等操作，还涉及目标对象识别、空间关系理解、阶段依赖、环境变化和历史信息保持。系统通过认知决策与运动控制的分工协作，连接任务规划、实际执行和反馈验证，形成完整的具身任务闭环。

二、系统架构：认知大脑与运动小脑
1. 认知规划层——大脑
认知大脑依托Agnes Harness获取用户目标、注册场景和可用技能信息，在已支持的任务范围内完成目标解析、技能选择与阶段编排，输出可审查的结构化任务计划。
大脑负责回答“操作什么、执行哪些阶段、按何种顺序推进”，不直接生成逐步机械臂控制信号。阶段指令、检查规则和执行预算受到技能目录与程序校验约束，使语言规划能够落入明确的执行边界。
2. 运动执行层——小脑
运动小脑由VLA动作策略与执行协调层共同构成。VLA融合阶段指令、当前视觉观测和机器人状态，生成连续控制动作；执行协调层维护阶段状态、动作预算、策略切换和复位工具，负责将高层计划落实为实际操作。
多个阶段在同一个物理场景中连续执行，保留前序操作引起的物体位置和交互状态变化。阶段完成后，系统清理剩余动作并切换下一目标，避免旧指令继续执行而干扰后续任务。
3. 执行验证枢纽——Harness
Agnes Harness连接认知大脑、远程运行服务与仿真环境，承担计划接入、工具调用、运行管理和结果呈现。

三、核心功能与技术特点
1. 自然语言规划与工具调用
系统将用户的自然语言目标拆分为多个阶段，支持不同长度的任务计划，并展示各阶段的指令和执行条件。计划只能使用已注册的技能和工具，经过程序检查后交给执行器运行，保证规划与实际执行能力相匹配。
2. 小脑记忆管理与连续阶段执行
小脑不仅负责动作执行，还通过执行协调层维护结构化任务记忆，记录当前目标、阶段顺序、完成历史、当前完成条件和执行异常。
多个阶段在同一个仿真场景中连续执行，保留前序操作造成的环境变化。阶段切换时，小脑清理上一阶段未执行的动作，更新目标，并重新建立VLA策略会话；任务记忆则继续保留，避免动作策略切换导致任务进度丢失。
3. 面向状态泛化的机械臂复位与阶段衔接
原子动作模型通常从较固定的机械臂姿态和视角开始执行。长任务中，上一阶段结束后的机械臂位置、朝向和腕部视角可能明显改变，使下一阶段面对不同于训练示教的起始状态，增加对象选择和动作执行的难度。
系统记录阶段开始时的机械臂关节姿态，在阶段结束后通过真实、限速的运动回到参考姿态，并结合碰撞检查和路径规划减少回位过程中的干扰。这一设计旨在减小阶段之间的机器人状态差异，缓解由动作衔接引起的输入分布变化，提高已有原子技能在连续任务中的适用性。
4. 实时画面与过程记录
用户可在Agnes网页端查看主视角、腕部视角、阶段进度和运行状态。系统保存连续录像、动作轨迹、任务计划和验证结果，便于回放执行过程、分析失败原因和复核实验结果。
5. 运行管理与故障分类
任务提交后在后台执行，支持状态查询和停止操作。同一执行会话只允许一个任务运行，重复提交不会重复启动，并通过动作预算和持久化记录管理运行过程。系统分别记录规划接口失败、动作预算耗尽和复位失败，区分系统接入问题与机器人操作问题。

四、原型验证与应用价值
任务与实验设置
实验基于LIBERO仿真环境构建8个自定义长时程任务，由同类操作、混合操作及各自的位置扰动版本组成，每类分别设置五阶段和八阶段任务。任务包含物体搬运、容器收纳、抽屉操作和炉灶操作等原子技能。

本轮比较三种方法：
（1）InternW0-Δ端到端：输入完整长任务指令，不提供阶段切换和复位辅助。
（2）AtomicVLA端到端：采用相同任务目标，直接执行完整长任务。
（3）本方法：通过Agnes Harness调用大模型选择已注册技能、组织阶段计划，再由InternW0-Δ逐阶段执行，配合结构化任务记忆、仿真状态检查和机械臂复位。
本轮规划模型为deepseek-flash，采用文字目标和注册技能目录进行规划，不进行开放式视觉规划。动作模型固定已有权重，不针对本批任务训练或微调。
每种方法对8个任务各尝试一次，共24次计划执行尝试。随机种子固定为47，初始状态索引为0；同一任务在不同方法间使用相同初始仿真状态，每次尝试独立初始化场景，阶段之间不重置环境，不自动重跑失败回合。

运行预算如下：
设置	五阶段任务	八阶段任务
总控制步数上限	3500步 	5600步
VLA策略调用上限	250次	400次
执行时间上限	1200秒	1920秒

任一预算达到上限即停止。复位动作计入总控制步数。本方法每阶段VLA动作最多400步；单次复位最多1000步，路径搜索累计最多10秒，执行过程中最多重新规划2次。复位要求最大关节误差不超过1度、末端位置误差不超过5厘米、朝向误差不超过10度。

结果解释与应用价值
本轮结果说明，在部分任务中，将长指令拆分为阶段目标，并结合状态检查、执行记忆和复位辅助，可以使机器人完成端到端方法未完成的完整任务。但尚不能判断改进分别来自规划、记忆还是复位，需要进一步开展模块消融实验。

五、后续研究：潜在空间认知、跨阶段记忆与策略协同对齐
下一阶段计划在运动小脑中引入可学习的latent空间感知与记忆模块，探索以潜在表征作为感知记忆模块与VLA动作专家之间的条件接口。
1. 对象级潜在空间表征
从视觉观测与机器人状态中提取对象特征，编码目标身份、相对位置、目标区域和机械臂状态，并通过监督约束将潜在表征与可解释的空间关系对齐。
研究目标是为动作策略提供与当前场景一致的目标表示，缓解仅依赖文字方位描述时的对象选择与空间指代歧义。
2. 面向长程依赖的潜在记忆
维护跨阶段持续更新的latent记忆状态，将关键历史观测、执行动作和阶段结果压缩为有限数量的记忆特征，重点保留对象身份、初始位置、操作后的变化及后续约束。
该记忆不以保存全部视频为目标，而是学习保留对后续控制有用的信息，使系统在遮挡、视角变化或机械臂回位后，仍能保持目标对象与任务历史之间的关联。
3. 面向动作控制的潜在协同接口
认知大脑继续输出可解释的阶段目标；运动小脑融合目标语义、当前空间感知与历史记忆，生成latent子目标特征，经可学习投影或适配器接入VLA，为动作生成提供更紧凑的条件指导。
这里的“协同语言”是经过训练对齐的潜在特征，而非自然语言或任意向量。不同模块之间需要建立明确的接口与表征对应，不能假设它们天然共享同一个latent空间。
4. 分阶段联合训练与轻量微调
初期冻结认知大脑与VLA主干，优先训练空间编码器、潜在记忆模块和接口适配器；接口稳定后，再联合优化小脑的latent模块与VLA轻量可训练参数，使记忆表征与动作策略共同适应长程任务。
训练数据优先复用公开示教轨迹，利用仿真对象状态辅助生成空间与阶段标注，并补充少量长任务轨迹。训练目标结合动作模仿、空间关系对齐和跨时序对象一致性，使潜在表征保留真正有助于动作控制的信息。
最终通过端到端基线、现有分阶段系统、latent增强系统及记忆模块消融实验，在统一任务、种子和预算下比较原生整任务成功、对象误选和阶段失败情况，验证潜在空间认知与记忆机制的实际价值。
